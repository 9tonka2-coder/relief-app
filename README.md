# relief.exe — 画像を3Dプリント用モデルに

写真をアップロードすると、明るさを高さに変換した立体的なレリーフ（浮き彫り）モデルを生成し、
3Dプレビュー表示 → STLファイルとしてダウンロードできるツールです。

このフォルダには、Webサイトとして公開したり、Google Play / Microsoft Store 向けに
パッケージ化したりするために必要な一式が入っています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（Three.jsを内蔵、完全オフライン動作） |
| `manifest.json` | PWA（インストール可能なWebアプリ）用の設定 |
| `service-worker.js` | オフラインキャッシュ用（PWAのインストール条件を満たすため） |
| `icon-192.png` / `icon-512.png` | アプリアイコン（通常用） |
| `icon-512-maskable.png` | アプリアイコン（Android adaptive icon用） |

**重要**: これらのファイルは必ず同じフォルダに置いたまま、まとめてホスティングしてください。
`index.html` だけを単体で開いても動作はしますが（PWA機能とAI設定提案以外は問題なく使えます）、
ストア公開用にパッケージ化するには全ファイルを同一オリジンに置く必要があります。

## 1. まずはWebサイトとして無料公開する

GitHub Pages・Netlify・Vercel などにこのフォルダをそのままアップロードするだけで、
HTTPSのURLが手に入ります（無料）。これがストアパッケージ化の前提になります。

例（GitHub Pages）:
1. GitHubで新しいリポジトリを作成し、このフォルダの中身をすべてアップロード
2. リポジトリの Settings → Pages で公開を有効化
3. 数分で `https://ユーザー名.github.io/リポジトリ名/` として公開される

## 2. Google Play ストアに出す場合

- Google Playデベロッパー登録: 一回限り $25（買い切り、更新料なし）
- ホスティングしたURLを [PWABuilder](https://www.pwabuilder.com) に入力
- 「Android」パッケージを選択 → TWA (Trusted Web Activity) 形式の `.aab` が生成される
- 生成された `.aab` を Google Play Console からアップロード
- 個人アカウントは公開前に12人以上のテスターによる14日間の非公開テストが必須（2026年時点のルール）

## 3. Microsoft Store に出す場合

- 個人・法人デベロッパー登録: **無料**（2026年時点、登録料なし）
- 同じく [PWABuilder](https://www.pwabuilder.com) にURLを入力
- 「Windows」パッケージを選択 → `.msix` が生成される
- Partner Center からアップロード

## プライバシーについて（ストア申請フォーム用）

このアプリは画像処理・3Dモデル生成をすべてブラウザ内で完結させており、
サーバーへのデータ送信は一切行いません。個人情報やアップロード画像の収集・保存はありません。
Google Play の「データセーフティ」フォームや Microsoft Store のプライバシーポリシー欄には
「データ収集なし」として申告できます。
